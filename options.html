该权限为可选项，只在你点击后才会申请。不授权时插件仍可记录下载信息，但无法计算哈希。

关于与免责声明

  • 本扩展是辅助判断工具，结果来自 VirusTotal 聚合的第三方引擎，不能替代专业杀毒软件； 未检出不等于绝对安全。
  • 默认只把 MD5 / SHA-256 哈希发送给 VirusTotal。只有你主动点击「上传查毒」时，文件内容才会被上传。
  • 哈希通过重新读取下载链接计算。若下载需要登录、链接已过期或来源返回了错误页面， 计算出的哈希可能与本地文件不一致，界面会给出警示。
  • 默认不携带任何 Cookie。只有你在某条记录上点击「携带登录信息重试」并确认后， 该次请求才会带上该站点的登录态；且带登录态的请求不跟随任何重定向， 避免凭证被带到跳转目标。
  • VirusTotal 免费 API 仅限非商业用途；商业场景请遵守其 服务条款。
